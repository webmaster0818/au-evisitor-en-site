| 案 | 内容 | 16pxでの読みやすさ |
| --- | --- | --- |
| B1 | ペトロールの角丸＋白い国土＋星5つ | ○ |
| B2 | 円形バッジ（紺の円に白い国土と星） ← **暫定採用** | ○（NZサイトで採用したA2と同じ円形＝シリーズで統一できる） |
| B3 | オレンジ地＋白い国土＋星1つ | ◎（最も高コントラスト） |
| B4 | ペトロール＋下部にターコイズの海 | ○ |

⚠️ 生成画像は背景が「透明」ではなく白や模様が描かれていることがある。
   faviconにする前に**円の外側を透明に抜いてトリミング**する（NZのA2でも同じ手当てをした）。
⚠️ ico は必ず RGBA で保存する。RGBだと Next のビルドが
   `The PNG is not in RGBA format!` で落ちる。
